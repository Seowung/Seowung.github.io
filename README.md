# Seowung Leem — Personal Website

English-first website with a Korean language switch. Sections: Research, Faith, Interests, and Life in the US.

## Status
Private source repository. GitHub Pages is intentionally not enabled. Keep this repository private until the owner explicitly requests public release.

## Updating through the project chat
Edit `index.html`, `style.css`, and `app.js`. Bilingual copy is in the `en` and `ko` dictionaries in `app.js`. Keep both languages aligned. No personal biography, affiliation, publication, or sample post should be invented.

## Preview
Run `python3 -m http.server 4173` in this directory and open http://localhost:4173. This preview runs only while the server is active.

## Future release
After owner approval for public access, configure GitHub Pages for the repository root. No automatic publishing workflow has been added.
